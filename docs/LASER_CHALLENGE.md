# 레이저 챌린지 (LASER CHALLENGE)

손을 거울처럼 기울여 레이저를 반사시켜, 빨강 → 노랑 → 파랑 타깃을 **순서대로** 맞히는 교육용 게임입니다.
카오스 타워와 **같은 서버·카메라·손 인식**을 쓰고, 게임 화면만 따로입니다.

## 1. 실행 (일반 PC · 노트북)

**손 인식은 크롬 안에서 돌아갑니다** (웹캠 + MediaPipe WASM). 파이썬 서버는 기록·순위표만 맡아서 설치가 간단하고, 윈도우 보안 정책(스마트 앱 컨트롤 등)이 파이썬 opencv DLL을 막는 PC에서도 됩니다.

```powershell
# 윈도우 (PowerShell 또는 명령 프롬프트). Python 3.9 이상 아무 버전이나 됨
git clone -b laser-challenge https://github.com/novalab0401/EDU-contents
cd EDU-contents
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-lite.txt
.venv\Scripts\python server.py --no-camera
```
```bash
# 맥 · 리눅스
python3 -m venv .venv && .venv/bin/pip install -r requirements-lite.txt && .venv/bin/python server.py --no-camera
```

- 게임: 크롬에서 **http://localhost:8001/laser** → 카메라 **허용** (한 번만). `localhost`로 열어야 브라우저 카메라가 켜집니다 (다른 PC에서 `http://192.168...` 로 열면 막힘).
- 손 인식 화면: 게임 화면에서 **V 키** (카메라 영상 + 관절 + 거울 각도 `deg` + 쥠 여부). 왼쪽 아래 상태 줄에 "카메라 연결됨 · 손 N개 · fps"가 보입니다.
- 손 인식 모델: `models/hand_landmarker.task` 가 있으면 그걸 쓰고(인터넷 없는 전시장용), 없으면 인터넷에서 받아 옵니다. 미리 받아 두려면:
  ```powershell
  mkdir models
  curl.exe -L -o models\hand_landmarker.task https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
  ```
  (파일 크기가 약 7MB여야 합니다. 수백 바이트면 오류 페이지가 저장된 것 → 다시 받기)
- 데이터 보기: `/laser-data.html` · CSV: `/api/laser/plays.csv`
- **전시용 전체 화면**: 윈도우 `laser_windows.bat` (더블클릭) / 맥·리눅스 `./laser_kiosk.sh`. 크롬을 `--kiosk --autoplay-policy=no-user-gesture-required --use-fake-ui-for-media-stream` 으로 열어서 클릭 없이도 효과음이 나고 카메라 허용 팝업도 안 뜹니다.
- 카메라는 브라우저가 잡습니다. 다른 프로그램(카메라 앱·화상회의)이 카메라를 쓰고 있으면 "다른 프로그램이 카메라를 쓰고 있어요"가 뜹니다. 서버를 `--no-camera` 없이 켜면 파이썬이 카메라를 먼저 잡을 수 있으니 PC에서는 항상 `--no-camera`.
- **젯슨·오르벡 깊이 카메라**(예전 방식): 주소 뒤에 `?server` 를 붙이면 파이썬 서버의 손 인식(`/hand`)을 씁니다. 브라우저 카메라가 안 될 때(권한·카메라 없음·http 주소)도 자동으로 서버 손 인식을 시도합니다. 카메라가 하나도 없으면 마우스·키보드로 플레이됩니다.

## 2. 플레이 흐름

`대기 화면(스스로 푸는 데모)` → 난이도 카드 선택(클릭 · 손으로 1초 가리키기 · 키 2~5) → **MISSION 01 튜토리얼** (거울 1개, 입사각·반사각 표시) → **MISSION 04 「빛의 미로」** (타깃 4개, 거울 5개, 60초 · 6발) → 결과 → 오늘의 챔피언

| 입력 | 손 (카메라) | 키보드·마우스 (예비) |
|---|---|---|
| 거울 각도 | **손가락이 가리키는 방향 = 거울 방향** (5° 단위로 끊김). 왼손 = 왼쪽 거울, 오른손 = 오른쪽 거울. 손이 하나면 왼쪽에 있을 때 왼쪽 거울, 오른쪽에 있을 때 오른쪽 거울 | 휠 · ← → (5°), Tab 거울 바꾸기 |
| 발사 | **주먹을 쥐면 발사** (쥐기 직전 각도로 고정됨) | Space · 마우스 클릭 |

- 점선 = 미리보기(첫 반사까지만). 나머지 경로는 쏴 봐야 알 수 있습니다 → 반사 법칙을 생각해서 푸는 퍼즐.
- 손이 사라지면 거울 각도를 유지하고 "손을 보여주세요"가 뜹니다.

### 운영자 키

| 키 | 동작 |
|---|---|
| Enter | 시작 (대기 화면) / 처음 화면으로 (결과 화면) / 결과로 넘기기 (처방 화면) |
| 2 | **쉬움**: 튜토리얼 → MISSION 02 (두 거울, 타깃 2개, 60초 · 6발) |
| 3 | **보통**: 튜토리얼 → MISSION 03 (타깃 3개, 45초 · 5발) |
| 4 | **기본**(Enter와 같음): 튜토리얼 → MISSION 04 (타깃 4개, 거울 5개, 60초 · 6발) — 정답이 5° 격자에서 딱 1가지 |
| 5 | **어려움**: 튜토리얼 → MISSION 05 「광학 마스터」 (타깃 5개, 거울 7개, 75초 · 6발) — 정답 1가지 |
| L | **라이브 모드 켜기/끄기** (레이저 상시 ON, 처음 화면의 칩으로도 가능) — 켜 둔 상태로 난이도를 고르면 라이브로 시작. 아래 "두 가지 방식" 참고 |
| N | 튜토리얼 · 카운트다운 건너뛰기 |
| R | 지금 미션 다시 시작 |
| Esc | 처음 화면으로 |
| V · M · F | 손 인식 화면(카메라 + 관절 + 각도) · 소리 끄기 · 전체 화면 |

결과 화면에서 오늘 TOP 5에 들면 이름칸이 뜨고 이름이 **미리 채워져** 있습니다(아이가 안 쳐도 됨). Enter로 저장하거나, 그냥 두면 약 18초 뒤 자동 저장 후 처음 화면으로 갑니다. 손을 든 채로 처음 화면에 돌아와도, 손이 카드 밖으로 한 번 나가야 다음 게임이 시작됩니다.

### 두 가지 방식: 발사 모드 vs 라이브 모드

| | 발사 모드 (기본, Enter) | 라이브 모드 (L 키) |
|---|---|---|
| 레이저 | 주먹(Space)으로 **발사**, 45초 · 5발 | **항상 켜져 있음**, 각도를 바꾸면 경로가 바로 따라옴 |
| 미리보기 | 첫 반사까지만 (나머지는 쏴 봐야 앎) | 전체 경로가 실시간으로 보임 |
| 클리어 | 타깃 순서대로 맞히면 (여러 발에 나눠도 됨) | **한 줄기 빔**으로 빨강→노랑→파랑을 0.5초 이상 유지 |
| 주먹 | 발사 (각도는 쥐기 직전 값으로 고정) | **각도 고정** (발사 없음) |
| 점수 | 타깃×1000 + 남은 시간×10 + 남은 발수×150 | 타깃×1000 + 남은 시간×10 |
| 별 | ★ 클리어 · ★★ 3발 이하 · ★★★ 2발 이하+15초 남음 · ONE SHOT 배지 | ★ 클리어 · ★★ 15초 이상 남음 · ★★★ 28초 이상 남음 |
| 순위표 | 오늘의 챔피언 (mission 3) | 따로 집계 (mission 13) — 발사 모드 순위표에 섞이지 않음 |

발사 모드는 "생각하고 쏘는" 퍼즐, 라이브 모드는 "돌려 보면서 원리를 찾는" 탐색에 가깝습니다. 부스에서는 처음 하는 사람·아이들에게 라이브(또는 튜토리얼), 도전하는 사람에게 발사 모드를 권합니다. 비교용으로 둘 다 두었고, 하나로 정하면 나머지는 키로만 접근하게 두면 됩니다.

## 3. 점수 · 별 · 진단

- (발사 모드 기준) 점수 = 맞힌 타깃 × 1000 (+ 클리어 시: 남은 시간(초) × 10 + 남은 발수 × 150)
- 별: 클리어 ★ · 3발 이하 ★★ · 2발 이하 **그리고** 15초 이상 남음 ★★★ · 1발 클리어 = **ONE SHOT** 배지
- 타깃은 센서입니다 (빛이 지나가면 활성화, 계속 나아감). 순서가 틀리면 인정 안 됨 + 안내. 한 발에 세 타깃을 다 지나가게 해도 됩니다.
- **실패 진단·처방**: 같은 광학 엔진으로 각도를 전부 탐색해서 "왼손 거울: 시계 방향으로 5° 더"처럼 *가장 적게 돌리는* 정답을 알려 주고, 정답 예시를 노란 점선으로 보여 줍니다.

## 4. 기록 · 개인정보

- `data/leaderboard.db` (SQLite, 카오스 타워와 같은 파일) 의 `laser_plays` 표. 한 판 = 한 줄 + 이벤트 로그(JSON).
- 이벤트: `MISSION_START`, `MIRROR_SELECTED`, `ANGLE_CHANGED`(거울 id·각도), `SHOT_FIRED`(발사 번호·거울 각도·광선 경로), `TARGET_HIT` / `TARGET_WRONG_ORDER`, `RAY_BLOCKED`, `MISSION_END`. 시각은 미션 시작 기준 ms.
- **카메라 영상·사진은 저장하지 않습니다.** 저장되는 것은 거울 각도와 게임 이벤트뿐입니다. 이름은 아이가 고른 별명(최대 10자)이고 실명을 받지 않습니다.
- 전시 전에 테스트 기록 정리: `/laser-data.html` 에서 삭제하거나 `data/leaderboard.db` 파일을 지우면 됩니다.

## 5. 현장 세팅 점검

1. 서버를 켜고 게임에서 **V 키** → 손을 들어 관절이 잡히는지, 손가락을 기울이면 `deg` 숫자가 바뀌는지 확인. (미리보기 화면은 거울처럼 보이므로 손가락을 오른쪽으로 기울이면 화면에서도 오른쪽으로 기웁니다.)
2. 카메라 높이는 가슴~얼굴 높이, 손은 카메라에서 **50~90 cm**. 두 손을 같이 들 때 둘 다 화면에 들어오는 거리를 확인.
3. 주먹이 잘 안 잡히거나 너무 잘 잡히면 `config.yaml` 의 `hand.grab_close` / `grab_open` (카오스 타워와 같은 값, 미리보기에 `open=` 숫자가 나옴).
4. 조명: 손 뒤가 너무 밝은 창이면 인식이 흔들립니다.
5. 5° 단위로 끊는 값은 `src/laser/levels.js` 의 `SNAP`, 떨림 평활은 `src/laser/input.js` 상단 상수.

## 6. 레벨 만들기·수정

`src/laser/levels.js` 에 레벨을 정의합니다. **정답 각도(`solution`)를 먼저 정하고** 타깃을 그 경로 위에 놓으세요. 그 뒤 `node tests/laser_unit.mjs` 를 돌리면 ① 정답으로 클리어되는지 ② 시작 배치가 이미 정답이 아닌지 ③ 정답이 5° 격자 위인지 ④ 정답이 1~3가지뿐인지(너무 쉽거나 불가능하지 않은지)를 검사합니다. *거울 위치는 고정*입니다 (위치까지 손으로 맞추게 하면 허용 오차가 ±6px로, 손 떨림으로는 풀 수 없다는 것을 테스트로 확인해서 각도만 조작하게 했습니다).

## 8. 알려진 한계 · 확인이 필요한 것

- **실제 손 모델로 손을 인식하는 것은 아직 확인하지 못했습니다.** 브라우저 쪽은 가짜 카메라로 카메라 연결 · 라이브러리 로딩 · 인식 엔진 초기화까지, 계산은 가짜 손 데이터로 검증했습니다. 처음 켜면 **V 키**로 각도(`deg`)·주먹 인식을 꼭 확인하세요. 주먹 기준은 `src/laser/handmath.js` 의 `GRAB_CLOSE`/`GRAB_OPEN`, 손 움직임 범위는 `NX_GAIN`.
- 윈도우·맥 실행 스크립트(`laser_windows.bat`, `laser_kiosk.sh`)는 이 환경에서 실행해 보지 못했습니다. 크롬 경로가 다르면 고치세요.
- 두 손을 동시에 쓸 때 서로 겹치거나 한 손이 화면 밖이면 한 손으로 처리됩니다 (한 손 규칙으로 계속 플레이 가능).

## 조작감 설정 (2026.11.18 조정)
- 각도 부드럽게(`ANGLE_TAU` 0.16초) · 스냅 경계 히스테리시스 2.4° → 손 떨림에 덜 민감 (`src/laser/input.js`)
- 주먹 인식은 연속 3프레임 필요 + 쥐기 직전 0.25초 이상 펴 있어야 발사 → 인식 깜빡임으로 인한 실수 발사 방지
- 한 손으로도 가능: 손이 화면 왼쪽이면 왼손 거울(H1), 오른쪽이면 오른손 거울(H2)을 조종 (가운데 ±0.3은 직전 거울 유지). 조종 중인 거울은 화면에서 강조. 한 번 맞춘 각도는 손을 내려도 유지
- 손 인식 화면(카메라 + 관절 + 각도)은 기본으로 켜짐, V 키로 끄기

## 소리 · 배경음악 (2026.11.18)
- 효과음과 배경음악(BGM)은 모두 파일 없이 브라우저에서 합성 (오프라인 가능, 저작권 문제 없음). 대기·튜토리얼·카운트다운은 잔잔한 BGM, 본 게임은 베이스·비트가 붙은 BGM, 결과 화면은 BGM을 끄고 효과음만. **M 키 = 음소거**
- **브라우저는 클릭·키 입력 전에는 소리를 막음** → 손으로만 시작하면 소리가 안 날 수 있음. 처음 화면에 "🔇 소리가 안 나요" 안내가 뜨며, 화면을 한 번 클릭하거나 아무 키나 누르면 켜짐. 전시용 `laser_windows.bat`·`laser_kiosk.sh`로 크롬을 켜면(`--autoplay-policy=no-user-gesture-required`) 조작 없이도 바로 소리가 남
- 쏠 때 각도가 흔들리는 문제: 손가락이 접히기 시작하면(펴짐 비율 < 1.5) 각도 갱신을 멈추고, 발사 각도는 쥐기 0.5초 전 값으로 고정, 주먹을 푼 뒤 0.4초도 각도 유지 (`src/laser/input.js`의 `CLOSING_OPEN` · `FREEZE_BACK` · `RELEASE_HOLD`)
